# HalfLife Caffeine v1.6.0 — new Finnish strings

Version 1.6.0 adds these things:

- The main screen and the glance show *when* it's safe to sleep as a clock time ("Sleep safe at 22:07") instead of a countdown ("Sleep safe in 3h 20m"). A phone setting switches back to the countdown.
- When that time is on the next day, the line says so ("Safe tomorrow 16:37").
- On watches set to 12-hour time, times show as "10:07 PM".
- A new setting for the level (25–100 mg, default 50) below which the watch says it's safe to sleep.

Eleven new strings need a Finnish translation. **Max** is the most characters that fit on the smallest watches, counted with the example filled in. Settings rows (phone) have no limit.

## Watch screens

| Key | Where it shows | Max | English | Filled-in example |
|---|---|---|---|---|
| `SummarySleepSafeAt` | Main screen. `$1$` is a clock time. | 24 | `Sleep safe at $1$` | Sleep safe at 10:07 PM |
| `GlanceSafeAt` | Glance status line. `$1$` is a clock time. | 19 | `Safe at $1$` | Safe at 10:07 PM |
| `TimeAM` | Suffix after a 12-hour time before noon (9:03 AM). Only on watches set to 12-hour time. | 4 | `AM` | |
| `TimePM` | Suffix after a 12-hour time from noon (10:07 PM). | 4 | `PM` | |
| `SummarySleepSafeTomorrow` | Main screen, when the safe time is on the next day (caffeine late in the evening). `$1$` is a clock time. | 24 | `Safe tomorrow $1$` | Safe tomorrow 10:07 PM |
| `GlanceSafeTomorrow` | Glance status line, same case. `$1$` is a clock time. | 19 | `Tomorrow $1$` | Tomorrow 10:07 PM |

For consistency, here are the existing Finnish strings for the countdown, which stays available as a setting:

| Key | English | Current Finnish |
|---|---|---|
| `SummarySleepSafeIn` | `Sleep safe in $1$` (3h 20m) | `Uni OK: $1$` |
| `GlanceSafeIn` | `Safe in $1$` | `Uni OK: $1$` |
| `Clear` | `Clear` | `Uni OK` |

## Phone settings (Garmin Connect app and companion page)

| Key | Where it shows | English |
|---|---|---|
| `SettingSleepFormat` | Settings title: how the main screen and glance show when it is safe to sleep | `Sleep time shown as` |
| `SleepFormatClock` | Option: a clock time, e.g. "Sleep safe at 22:07" | `Clock time` |
| `SleepFormatCountdown` | Option: a duration, e.g. "Sleep safe in 3h 20m" | `Countdown` |
| `SettingSleepSafeMg` | Settings title: the caffeine level (mg) below which the watch says it is safe to sleep | `Safe to sleep below (mg)` |
| `CSleepSafeMg` | Same, as a field label on the companion page | `Safe to sleep below (mg)` |

## Questions

1. With `Uni OK: $1$`, a clock time ("Uni OK: 22:07") and a countdown ("Uni OK: 3t 20min") read alike. Is that clear enough, or should the clock-time line say it differently (something like "Uni OK klo 22:07")?
2. The watch writes times as `22:07`. Finnish usually writes `22.07`. Does `22:07` look wrong on a Finnish watch, or is it fine (the watch's own clock uses a colon)?
3. Finland uses the 24-hour clock, so `TimeAM`/`TimePM` will rarely show. Is "ap." / "ip." right, or should they stay "AM" / "PM"?
