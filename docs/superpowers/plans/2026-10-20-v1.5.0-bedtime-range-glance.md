# v1.5.0 Bedtime Preview, Graph Range, Glance Bar — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the projected caffeine at bedtime for each drink in the Add Drink menu, let SELECT cycle the Timeline graph between 4h/8h/12h windows, and draw today's intake-vs-limit bar on the glance.

**Architecture:** One new pure model method (`CaffeineModel.getLevelWithDose`), two new glance-safe helpers in `Util` (`getDailyLimit`, `intakeColor`), static range helpers on `TimelineView`, and view/delegate wiring. No new screens, no new settings; one new translated string (`MenuBedPreview`).

**Tech Stack:** Monkey C, Connect IQ SDK 9.x, widget app (`minApiLevel 3.2.0`), PowerShell tooling (`tools/run-tests.ps1`, `tools/build-translations.ps1`, `tools/sim-matrix.ps1`).

**Spec:** `docs/superpowers/specs/2026-10-20-v1.5.0-bedtime-range-glance-design.md`

## Global Constraints

- Read `CLAUDE.md` first. Rules that bite here:
  - `import Toybox.*`, never `using`. Omit type annotations in function signatures.
  - Drawing coordinates must be integers: `h * 52 / 100`, never `h * 0.52`.
  - Code reachable from the glance must be in a `(:glance)` class/module. `Util` and `Colors` are `(:glance)` modules; `TimelineView` and `AlertManager` are **not** — the glance must not call them.
  - Strings are loaded once in `initialize()` (views) or once per menu build (delegates), never in `onUpdate`.
  - All user-visible text comes from `translations/en.csv` via `pwsh tools/build-translations.ps1`; never edit `resources*/strings.xml` or the `I18N` block in `companion/settings/index.html` by hand.
  - Use `Colors.*`, never hex literals, for new drawing.
- Sleep-safe threshold stays 50 mg; daily-limit default is 400 mg (`resources/properties.xml`); warning threshold is 80 % (`AlertManager.WARNING_THRESHOLD = 0.8`), applied as `intake >= (limit * 0.8).toNumber()`; over-limit is `intake >= limit`.
- Timeline ranges, in hours past / hours future / sample minutes: `[2, 4, 10]`, `[4, 8, 15]` (default, index 1), `[6, 12, 20]`. Storage key `timelineRange` holds the index.
- `MenuBedPreview`: `where` = `watch`, `max` = 20, `sample` = `999|999`, English `$1$ mg · bed $2$ mg`.
- Work on branch `feat/v1.5.0` off `main`. Commit after every task with the `Co-Authored-By` line the session requires.
- Tests: `pwsh tools/run-tests.ps1` (exit code 0 = all pass). Tests that use "now" can fail in the first hour after local midnight — rerun later rather than "fixing" them.
- Single-device build check: `monkeyc -f monkey.jungle -d vivoactive5_sim -y D:/Garmin/Key/developer_key -o bin/CoffeTracker.prg -w -r` (if `monkeyc` is not on PATH, use the `bin/monkeyc.bat` of the SDK named in `%APPDATA%/Garmin/ConnectIQ/current-sdk.cfg`).

## Review Focus

1. **Bedtime already passed tonight** (e.g. 23:30 with bedtime 22:30): `getBedtimeEpoch` rolls to tomorrow; the preview must show a small, non-negative number, never crash or show the drink's full mg. Covered by Task 1's "dose long before atEpoch" test plus the manual check in Task 6.
2. **Corrupt or stale `timelineRange` in Storage** (null, -1, 3, a Float or String from an older/other build): the Timeline must open at 8h, not crash. Covered by Task 2's `rangeIndex` tests.
3. **Daily limit synced from the phone as 0, negative, null or a Float**: glance and Summary must not divide by zero or show a full red bar for no reason. Covered by Task 2's `sanitizeDailyLimit` tests.
4. **Glance with no drinks today but yesterday's caffeine still decaying**: bar shows an empty track (intake is today's sum since local midnight), number still shows the level. Covered by Task 2's `intakeColor(0, …)` test and Task 5's manual check.
5. **Long translated sub-label on a narrow round menu** (fenix6, fr255s): `MenuBedPreview` filled with `999|999` must stay within 20 characters in every language. Enforced by `build-translations.ps1 -Require` in Task 3.

```monkeyc
    // Daily limit in mg. A value synced from the phone can be missing, a Float,
    // or nonsense; anything that is not a positive number means the default 400.
    function sanitizeDailyLimit(value) {
        if (value instanceof Lang.Number || value instanceof Lang.Float) {
            var n = value.toNumber();
            if (n > 0) { return n; }
        }
        return 400;
    }

    function getDailyLimit() {
        return sanitizeDailyLimit(Application.Properties.getValue("dailyLimit"));
    }

    // Colour for today's intake against the limit; same thresholds as AlertManager.
    function intakeColor(intake, limit) {
        if (intake >= limit) { return Colors.DANGER; }
        if (intake >= (limit * 0.8).toNumber()) { return Colors.WARNING; }
        return Colors.ACCENT;
    }
```

```monkeyc
    // Graph windows: hours past, hours future, sample step in minutes.
    // The step grows with the window so a redraw costs about the same.
    // Class constants are static in Monkey C: TimelineView.RANGES works without an instance.
    const RANGES = [[2, 4, 10], [4, 8, 15], [6, 12, 20]];
    const DEFAULT_RANGE = 1;
    const RANGE_KEY = "timelineRange";

    // Index into RANGES from a stored value; anything unexpected means the default.
    static function rangeIndex(stored) {
        if (stored instanceof Lang.Number && stored >= 0 && stored < RANGES.size()) {
            return stored;
        }
        return DEFAULT_RANGE;
    }

    static function nextRange(index) {
        return (index + 1) % RANGES.size();
    }
```

class TimelineDelegate extends WatchUi.BehaviorDelegate {

    private var _view;

    function initialize(view) {
        BehaviorDelegate.initialize();
        _view = view;
    }

    // START, or a tap on touch watches: cycle the graph window 4h → 8h → 12h.
    function onSelect() {
        _view.cycleRange();
        return true;
    }

    // Swipe down (touch) OR DOWN button (non-touch) → log view
    function onNextPage() {
        var view = new LogView();
        WatchUi.switchToView(view, new LogDelegate(view), WatchUi.SLIDE_UP);
        return true;
    }

    // Swipe up (touch) OR UP button (non-touch) → back to summary
    function onPreviousPage() {
        WatchUi.switchToView(new SummaryView(), new SummaryDelegate(), WatchUi.SLIDE_DOWN);
        return true;
    }

    // Non-touch widgets that don't auto-route DOWN/UP to next/prev page —
    // catch raw key events and dispatch manually.
    function onKey(keyEvent) {
        var key = keyEvent.getKey();
        if (key == WatchUi.KEY_DOWN) { return onNextPage(); }
        if (key == WatchUi.KEY_UP)   { return onPreviousPage(); }
        return false;
    }
}

```monkeyc
        // Status line. Long durations in the longer languages run past the
        // edge of the glance; step down a font size when they do.
        var statusFont = Graphics.FONT_GLANCE;
        if (dc.getTextWidthInPixels(statusText, statusFont) > dc.getWidth()) {
            statusFont = Graphics.FONT_XTINY;
        }
        var statusY = h * 72 / 100;

        // Today's intake against the daily limit, in the gap between the
        // number and the status line (same colours as the Summary bar).
        var barH = (h < 60) ? 2 : 3;
        var numBottom = numY + dc.getFontHeight(Graphics.FONT_GLANCE_NUMBER) / 2;
        var statusTop = statusY - dc.getFontHeight(statusFont) / 2;
        var barY = (numBottom + statusTop) / 2 - barH / 2;
        var barW = dc.getWidth();
        dc.setColor(Colors.TRACK, Graphics.COLOR_TRANSPARENT);
        dc.fillRectangle(0, barY, barW, barH);
        var fillW = barW * intake / limit;
        if (fillW > barW) { fillW = barW; }
        if (fillW > 0) {
            dc.setColor(Util.intakeColor(intake, limit), Graphics.COLOR_TRANSPARENT);
            dc.fillRectangle(0, barY, fillW, barH);
        }

        dc.setColor(Colors.TEXT_SECONDARY, Graphics.COLOR_TRANSPARENT);
        dc.drawText(0, statusY, statusFont,
            statusText, Graphics.TEXT_JUSTIFY_LEFT | Graphics.TEXT_JUSTIFY_VCENTER);
    }
```

`intake` and `limit` are Numbers, so `barW * intake / limit` is integer math (no Float coordinates). `limit` is never 0 (Task 2).
